## Usage Instructions

### When Writing a New Chapter
1. Review this file to recall recent plot developments
2. Check "Active Threads" to see what's pending
3. Check "Unresolved Foreshadowing" for opportunities to pay off setups
4. Check character milestones to ensure progression

### After Completing a Chapter
*(novel-summarizer skill handles this automatically)*

1. Add any new plot arc developments
2. Record character milestones if significant
3. Add new foreshadowing to "Unresolved" section
4. Move paid-off foreshadowing from "Unresolved" to "Resolved"
5. Update "Quick Chapter Summary" with one-line description
6. Increment "Current Chapter" at the top

### Maintenance
- Every ~20 chapters: Review and clean up resolved items
- Mark completed arcs as "Resolved" and archive details
- Consolidate if the file gets too long (move old resolved items to archive)
