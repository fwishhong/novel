## Usage Instructions

This CLAUDE.md file serves as the **canonical reference** for the novel-writer skill.

**Before starting each chapter:**
1. Review the outline.md for the overall story direction
2. Check events.md for recent plot developments
3. Consult this file for character profiles and world rules

**After writing each chapter:**
- The novel-reviewer will check against this file
- The novel-summarizer will update events.md

**Updating this file:**
- Add new characters as they become recurring
- Update character relationships when they change
- Mark foreshadowing as "paid off" when resolved
- Increment chapter count and word count periodically
