# 小说创作工作室 🖊️

AI 辅助的长篇网络小说创作平台，帮助作者创作高质量、前后一致的长篇小说。

## ✨ 核心功能

### 📚 小说管理
- 创建和管理多部小说作品
- 设置小说类型、简介、大纲
- 追踪创作进度和统计数据

### 📝 智能章节编辑器
- 清爽的写作界面
- **AI 内容生成**：
  - 章节大纲自动生成
  - 场景描写辅助
  - 智能续写功能
  - 内容润色优化
- **实时分析**：
  - 可读性分析（字数、句长、难度）
  - 情感和节奏分析
  - 一致性检查（人物、情节、设定）
- 侧边栏显示相关人物和世界设定

### 👥 人物管理系统
- 详细的人物卡片（性格、背景、外貌、能力、目标）
- 人物关系网络
- 说话风格设定（保证对话一致性）
- 人物成长轨迹追踪

### 🌍 世界设定管理
- 多类别设定系统：
  - 地理环境
  - 力量体系（修仙、魔法等）
  - 政治势力
  - 文化习俗
  - 科技水平
- 记忆库系统（记录重要事件和规则）
- 时间线管理

### 📊 数据分析
- 总字数、平均章节长度统计
- 完成度追踪
- **情节张力曲线**分析
- 情节点追踪（伏笔管理）
- 智能写作建议

## 🚀 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 配置环境变量

创建 `.env` 文件：

```bash
cp .env.example .env
```

编辑 `.env` 文件，添加你的 Anthropic API Key：

```env
ANTHROPIC_API_KEY=your_api_key_here
```

> 💡 获取 API Key：访问 [Anthropic Console](https://console.anthropic.com/) 创建账号并获取 API Key

### 3. 初始化数据库

```bash
npx prisma generate
npx prisma db push
```

### 4. 启动开发服务器

```bash
npm run dev
```

打开浏览器访问 [http://localhost:3000](http://localhost:3000)

## 📖 使用指南

### 创建小说

1. 点击首页的"创建新小说"按钮
2. 填写小说标题、类型、简介、大纲
3. 点击"创建"进入小说工作区

### 管理人物

1. 进入小说详情页
2. 切换到"人物"标签
3. 点击"新增"创建人物卡片
4. 填写人物的详细信息（性格、背景、说话风格等）

### 添加世界设定

1. 切换到"世界"标签
2. 在"世界设定"子标签中添加设定
3. 在"记忆库"中记录重要事件和规则

### 创作章节

1. 在"章节"标签中点击"新建章节"
2. 填写章节标题
3. 可选：使用 AI 生成章节大纲
4. 点击"创建并编辑"进入编辑器

### 使用 AI 助手

在章节编辑器中：

1. 点击"AI 助手"按钮
2. 选择生成类型：
   - **完整章节**：根据要求生成整章内容
   - **场景描写**：生成特定场景
   - **续写**：基于已有内容继续创作
3. 输入生成要求
4. 点击"生成"

### 分析内容

1. 在编辑器中点击"分析"按钮
2. 查看：
   - **可读性指标**：句长、难度、情感、节奏
   - **一致性检查**：人物性格、时间线、设定是否有冲突
3. 根据建议优化内容

## 🎯 核心设计理念

### 一致性保障

- **自动上下文检索**：生成内容时自动查询相关人物、设定、事件
- **冲突检测**：AI 检查新内容是否与已有设定矛盾
- **人物语言模型**：每个角色有独特的说话方式
- **伏笔追踪**：记录埋下的伏笔，提醒回收

### 质量控制

- **可读性评分**：分析句式复杂度和节奏
- **情节张力曲线**：可视化故事起伏
- **重复词检测**：避免用词单调
- **情感一致性**：确保人物情绪合理变化

## 🛠️ 技术栈

- **前端框架**：Next.js 15 + React 19
- **UI 组件**：shadcn/ui + TailwindCSS
- **数据库**：SQLite + Prisma ORM
- **AI 服务**：Anthropic Claude API
- **状态管理**：Zustand
- **类型安全**：TypeScript

## 🎨 核心数据模型

- **Novel**：小说（标题、类型、大纲、状态）
- **Character**：人物（性格、背景、能力、关系）
- **Chapter**：章节（标题、内容、大纲、字数）
- **Scene**：场景（地点、时间、氛围、出场人物）
- **WorldSetting**：世界设定（分类、描述、重要性）
- **Memory**：记忆（类型、内容、相关人物）
- **PlotPoint**：情节点（伏笔、高潮、转折）
- **Timeline**：时间线（事件名称、日期、描述）
